# Get Linked 📱

## School Project (Class 11)

Get Linked is an Android application developed in Android Studio as a school project. The app simulates a secure task management system designed for structured organizations such as a military-style environment.

The system allows users (soldiers) to receive, manage, and complete tasks assigned by higher-ranked users. Each user belongs to a rank-based hierarchy, where higher ranks have the ability to assign tasks to lower ranks and supervise their progress.

---

## Main Concept

The idea behind Get Linked is to create a controlled, structured task system where:
- Users are organized by rank
- Higher ranks can assign tasks to lower ranks
- Task completion is tracked and supervised
- Communication and coordination happen inside secure groups

---

## Features

- 👥 **Rank-based system**
  - Users have different ranks
  - Higher ranks can assign more tasks and manage groups

- 📋 **Task management**
  - Create, assign, and complete tasks
  - Track task status and progress

- 🔔 **Notifications**
  - Users receive updates about new tasks and changes

- 👨‍👨‍👦 **Group system**
  - Users are organized into groups for structured task distribution

- 🔗 **Server communication (LAN-based)**
  - The app was designed to connect to a private Linux server over a local network
  - Uses SSH-based communication to interact with a backend system
  - Stores and retrieves data from an SQL database

---

## Technical Notes

This project was created in **Class 11**, at an early stage of learning software development.  
At the time, knowledge of **SSH, server architecture, and secure networking** was limited, so the implementation is simplified and primarily functional rather than production-level secure.

The system was designed to operate only in a **local area network (LAN)** environment, as originally intended, without external internet exposure.
